# Bundled Unicode fallback font

`NotoSansCJKsc-Regular.otf` comes from the [Noto CJK project](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf).
It is distributed under the SIL Open Font License 1.1 in
`NotoSansCJK-LICENSE.txt`. The editor embeds only glyphs needed for a replacement.

This font provides common Chinese, Japanese, and Korean glyphs and also covers
Latin and Cyrillic characters. It does not cover every Unicode character. The
exporter checks coverage and reports unsupported characters before changing a page.
